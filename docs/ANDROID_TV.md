# Android TV

Отдельная версия для игры с обычного пульта. Целевая приставка пользователя — KM9PRO с Android 9, указанная в чате о Samson VPN. Пресет содержит ARMv7 и ARM64; совместимость с конкретной Xiaomi Mi Box / TV Stick нужно подтверждать установкой на устройстве.

## Управление

- Меню: стрелки выбирают кнопку, OK открывает её. Выбранная кнопка обведена оранжевой рамкой.
- Бой: ↑/↓ меняют угол на 2°, ←/→ меняют силу на 5%. Удержание стрелки повторяет изменение. Траектория, угол и сила видны до броска.
- OK запускает кота. Следующее отдельное нажатие OK включает его способность в полёте до удара. Удержание OK не запускает способность автоматически.
- «Назад» открывает/закрывает паузу. В паузе стрелками доступны продолжение, звук, перезапуск и главное меню.
- После результата доступны повтор и следующий уровень кампании. «Назад» возвращает в меню.

Редактор построек скрыт в TV-меню: его жесты рассчитаны на мышь и касание. Кампания, выбор героев в песочнице, локальный прогресс и настройки звука сохранены. Подсказки пульта пока на русском; остальные экраны используют существующий выбор языка.

## APK и установка

Файл: `build/android/cats-vs-dogs-android-tv.apk`. Пресет **Android TV APK**, версия **1.0.0-tv**, package identifier `com.catsvsdogs.tv`. Телефонная версия `com.catsvsdogs.game` устанавливается отдельно; её прогресс автоматически не переносится.

APK подписан локальным тестовым ключом. Для обновлений сохраняйте тот же ключ; готовность к Google Play не подтверждена. Разрешите установку неизвестных приложений для файлового менеджера, из которого открываете APK. После установки ищите «Кошки против собак TV» в списке приложений телевизора.

Для установки через уже авторизованный ADB:

```powershell
& $AdbExe -s $DeviceSerial install -r build/android/cats-vs-dogs-android-tv.apk
```

Всегда указывайте конкретную приставку через `-s`. Не переключайте её экран, пока на ней работают из другого чата.

## Повторная сборка

Нужны Godot из `.godot-version`, официальный `android_source.zip` той же версии, JDK/SDK и настроенный тестовый ключ; общая настройка описана в [WORKFLOW.md](WORKFLOW.md).

```powershell
& tools/build-android-tv.ps1 -GodotPath $GodotExe
```

Скрипт использует локальный `.tools/android-export-profile`, если он существует. В другой среде настройте редактор или передайте `-EditorProfile` и `-TemplateArchive`. `-BuildToolsVersion` по умолчанию **36.0.0**; этот пакет должен быть установлен в выбранном SDK. Скрипт распаковывает отдельный шаблон в `build/android-tv/build`, добавляет TV-баннер 320×180 и объявления необязательного touchscreen/leanback в основной манифест. Godot создаёт категорию `LEANBACK_LAUNCHER`. Телефонный Gradle-проект `android/` не используется.

Баннер создаётся из собственного логотипа и локального шрифта:

```powershell
& $GodotExe --path . --script res://tools/generate_tv_banner.gd
```

## Проверка

```powershell
& tools/check.ps1 -GodotPath $GodotExe
& $GodotExe --path . --fixed-fps 60 --disable-vsync --script res://tests/tv_controls_test.gd -- --tv --capture-tv
```

`--tv` позволяет проверить TV-режим на ПК. Сценарий проверяет меню, границы прицела, настоящий физический запуск, способность, остановку полёта на паузе, фокус и возврат из результата в 1280×720, 1600×720 и 960×720. Снимки — `.artifacts/tv-*.png`. Это синтетический ввод на ПК, не проверка реального пульта, телевизора или производительности приставки.

На устройстве отдельно проверьте запуск из TV-лаунчера, стрелки, OK и «Назад», удержание стрелок/OK, возврат после Home, читаемость с дивана, звук, сохранение прогресса и обновление поверх предыдущего TV APK.
