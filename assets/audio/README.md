# Звуки игры

Все звуки собственные, синтезированы без чужих записей и сэмплов. Генераторы используют только стандартную библиотеку Python; готовые WAV входят в проект, поэтому для игры Python не требуется.

| Файлы | Назначение | Воспроизводимое создание |
| --- | --- | --- |
| `meow_classic.wav`, `meow_bomb.wav`, `meow_zigzag.wav` | Три тембра кошек, 0.43–0.50 s | `python tools/generate_meows.py` |
| `bark_scout.wav`, `bark_armored.wav`, `bark_jumper.wav` | Три тембра собак, 0.23–0.42 s | `python tools/generate_barks.py` |
| `sfx_tension.wav`, `sfx_release.wav`, `sfx_flight.wav` | Короткое натяжение, выпуск и воздух в начале полёта | `python tools/generate_sfx.py` |
| `sfx_wood.wav`, `sfx_glass.wav`, `sfx_stone.wav`, `sfx_metal.wav` | Принятые сильные удары и разрушение соответствующего материала | `python tools/generate_sfx.py` |
| `sfx_victory.wav` | Мелодия победы, 1.22 s | `python tools/generate_sfx.py` |
| `music_meadow.wav` | Тихий расслабляющий фон: мягкие аккорды и редкие ноты, петля 64 s | `python tools/generate_music.py` |

Формат эффектов: PCM16, mono, 24 kHz, без зацикливания. Пиковая амплитуда мяу — 0.82, лая — 0.80, физических эффектов — 0.75. WAV загружаются заранее; генерации звука в каждом кадре нет.

Музыка — собственная композиция в ре мажоре без ударных: восемь медленных созвучий, тёплый синтезированный тембр и негромкие отдельные ноты. Исходник — PCM16, stereo, 24 kHz, пик 0.50 (−6.02 dBFS), около 6.15 MB. Ноты и мягкие отражения циклически продолжаются через границу записи, без паузы между повторами. Импорт WAV сохраняет всю петлю: `edit/loop_mode=2` (Forward), `edit/loop_begin=0`, `edit/loop_end=1536000`; нормализация и обрезка отключены. Узел `BackgroundMusic` в раунде играет её с уровнем −24 dB и плавным вступлением за 2.5 s; музыка подчиняется общей паузе и кнопке звука.

Все проигрыватели используют шину `SFX` и следуют общей паузе. Натяжение звучит один раз за жест; удержание и слабые касания тел остаются тихими. `WorldAudio` хранит шесть переиспользуемых голосов на раунд и объединяет события одного материала в пределах 80 ms. Звук разрушения доживает после удаления тела, победа получает голос даже при обрушении башни. Выход из раунда освобождает весь пул.

Тесты проверяют запуск, ограничения, паузу, выключение звука и освобождение потоков. Узнаваемость тембров и общий баланс громкости требуют прослушивания в игре.
